# سامانه آفلاین شناسنامه پروژه آزمایشگاه امنیت و کیفیت نرم‌افزار

نسخه `0.2.0` رابط فارسی و RTL فرم «درخواست ارزیابی امنیتی محصول» بانک ملی ایران است.

## اصلاحات این نسخه

- تطبیق دوباره با فرم HTML مرجع و حفظ تمام ۷۲ کنترل موجود.
- اضافه شدن گزینه انتخابی «سایر» برای دسته‌بندی محصول.
- ثبت حساب‌های تست استاندارد در خروجی JSON (`testAccounts`).
- خروجی نسخه‌دار با `schemaVersion` و نام‌گذاری سازگار با CRM (`submission`, `producer`, `classification`, `serverCredentials`, `approval`) در کنار `payload` قبلی.
- اعتبارسنجی فیلدهای ضروری، ایمیل‌ها، دسته‌بندی «سایر» و هش MD5 قبل از خروجی.
- ثابت شدن `submissionId` در طول تکمیل فرم و بازیابی آن هنگام ادامه پیش‌نویس.
- بازیابی پیش‌نویس‌های نسخه قدیمی با تکمیل خودکار فیلدهای تازه اضافه‌شده.
- ذخیره Draft و خروجی JSON به‌صورت اتمیک برای کاهش خطر فایل ناقص.

## اجرای توسعه

```bash
npm install
npm run dev
```

## بررسی و بسته‌بندی

```bash
npx tsc --noEmit
npm run build
npm run package
```

خروجی بسته‌بندی‌شده داخل `release` قرار می‌گیرد. ساخت Windows Installer باید روی Windows یا CI ویندوز انجام شود؛ محیط فعلی Linux نسخه AppImage تولید می‌کند.

## خروجی JSON

خروجی شامل نسخه نرم‌افزار `0.2.0`، نسخه فرم و Schema `1.1.0`، شناسه ارسال پایدار، بخش‌های نام‌گذاری‌شده برای CRM و `payload` سازگار با ساختار قبلی است.
